Data Analysis Projects
Python-based data analysis projects covering statistical methods for neuroscience and psychology research.
Datasets analyzed:

Seaborn exercise dataset (ANOVA, regression, confounding variables)
Seaborn attention dataset (t-tests, Tukey HSD, effect sizes)
Seaborn fMRI dataset (regression, polynomial regression, multiple regression)

Methods used: t-tests, ANOVA, Tukey HSD, linear regression, multiple regression, effect sizes (Cohen's d, eta-squared)
Tools: Python, pandas, scipy, statsmodels, seaborn, matplotlib, pingouin
